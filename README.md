# Food Loop

Helping Louisiana college students plan and manage their food budgets.

**Live site:** [bayou-basket-scout.lovable.app](https://bayou-basket-scout.lovable.app/)
## What it does

Food Loop helps Louisiana college students plan meals on a budget. It has one shared budget across:

- **Cook with groceries:** meal ideas that fit your equipment, pantry, and budget
- **Ready to eat:** pickup from local restaurants, corner stores, mini-marts, and gas-station kitchens
- **My Plan:** a saved meal plan and shopping list
- **Food assistance:** SNAP contacts and local food resources in Louisiana

## Why the project is useful?

Many students have limited kitchen access, limited transportation, and tight budgets. Food Loop plans around those limits. It also notes that a low price doesn't always mean a healthy meal.

## Getting started

**Use it:** open the [live site](https://bayou-basket-scout.lovable.app/). No install needed.

We're using [this API](https://prices.openfoodfacts.org/api/docs#/).

**Run it locally:**

Run it locally

Install Android Studio if you don't have it, and open it once so it finishes downloading the Android SDK.
On the Welcome screen, click Get from VCS (or in an open project: File > New > Project from Version Control).
Paste the repo URL and click Clone:
https://github.com/aedwardsxula/Food_Loop.git
When the project opens, click Trust Project, then let Gradle sync finish (watch the progress bar at the bottom). If it asks to install missing SDK components, accept.
Pick an emulator or plug in a phone with USB debugging on. To create an emulator: Device Manager > Create Device.
Click the green Run button (or press Shift + F10).

If you'd rather clone from the terminal, run git clone https://github.com/aedwardsxula/Food_Loop.git, then in Android Studio use File > Open and select the Food_Loop folder.
